# FORMWAHL Markenpaket

Eigenständiges fiktives Markenbild. Primary und Dark auf hellem Grund, Light auf dunklem Grund. PNG-Dateien besitzen echte Transparenz. SVG und PDF enthalten Vektorpfade. Favicon als SVG sowie ICO in 16, 32 und 48 Pixeln; Apple-Touch-Icon 180 Pixel.

Keine Markenrecherche. Vektor-PDF, keine Druckfreigabe, kein geprüftes CMYK/PDF-X-Profil.
